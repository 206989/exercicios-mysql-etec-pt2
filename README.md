# 🗄️ Evolução e Modelagem Avançada em MySQL

Este repositório registra a continuação dos meus estudos práticos em Banco de Dados, contendo os desafios e avaliações que desenvolvi no 1º ano da ETEC. O foco aqui é demonstrar a evolução na criação de estruturas relacionais complexas.

## 🔑 O que estou praticando nesta fase:
* **Relacionamentos de Tabelas:** Implementação prática de relações 1:1, 1:N e N:N (Muitos para Muitos).
* **Integridade Referencial:** Uso estratégico de chaves estrangeiras (`FOREIGN KEY`) para conectar dados de forma segura.
* **Mapeamento de Regras de Negócio:** Tradução de problemas do mundo real (como sistemas de vendas, bibliotecas ou cadastros) em tabelas organizadas.

## 📂 Estrutura dos Exercícios
Os arquivos estão organizados para demonstrar diferentes cenários de modelagem através de interfaces visuais e scripts estruturados:

* **Tabelas de Relacionamento:** Estruturação de chaves e restrições de integridade.
* **Garantia de Regras:** Aplicação de campos obrigatórios (`NOT NULL`) e valores únicos (`UNIQUE`).

## 🚀 Como testar e visualizar
1. Abra o seu ambiente MySQL (como MySQL Workbench ou phpMyAdmin).
2. Importe ou copie o código do script correspondente ao exercício.
3. Execute o script para gerar o esquema do banco de dados e visualizar os relacionamentos criados.
